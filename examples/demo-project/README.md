# Demo project

Небольшой независимый Maven-проект на Java 17 для проверки AutoTestForge. `PriceCalculator`
содержит проверки аргументов, скидку от десяти товаров и округление суммы.

В форме сайта укажите `examples/demo-project`, выберите `offline` и оставьте
«Без записи» включенным для первой проверки. Для генерации содержательных тестов
выберите подключенную LLM. Чтобы записать и запустить тесты, выключите «Без записи»
и включите валидацию; Maven загрузит нужные тестовые зависимости.

Проект намеренно не входит в reactor-сборку AutoTestForge.
