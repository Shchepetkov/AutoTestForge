AutoTestForge

Генератор модульных и интеграционных тестов для Java-проектов на базе ИИ

Внешний контекст для LLM

Можно добавить несколько MCP-источников (например, отдельные серверы Confluence, Jira, Zephyr) и/или загрузить XML/JSON/TXT экспорт из Zephyr/TMS. Этот контекст попадет в prompt, а LLM должна использовать его для сценариев и добавить в тест JavaDoc-заметку о покрытии и пробелах.

Файлы читаются браузером и отправляются как текстовый контекст; на сервере они не сохраняются как отдельные файлы.
