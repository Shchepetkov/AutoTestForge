Ваш первый запуск

Четыре шага от исходного кода до готовых тестов.

  1. Укажите папку Java-проекта

    Используйте путь на сервере AutoTestForge. Можно ограничить генерацию конкретными классами.

  2. Подключите модель

    Выберите Ollama, OpenAI или совместимый API. Укажите адрес и имя модели, затем проверьте подключение.

  3. Начните с пробного запуска

    Тесты будут сгенерированы без записи файлов. Режим «Без LLM» позволяет проверить установку без подключения к модели.

  4. Проверьте результат

    Для записи тестов выключите пробный режим. Для проверки и самоисправления включите соответствующую опцию; понадобятся Docker или Java и Maven/Gradle.
